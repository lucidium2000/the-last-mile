What is recorded, and what is not

Every finished run sends three initials, the run's own numbers (score, blocks, rows, steps, subway rides, TAM wins, seconds, how it ended, which power-ups were collected) and a random id the browser made up for itself, so repeat plays can be counted without counting a person twice. The set of ids never leaves the server — this page only ever receives the count.

There are no device, browser or location statistics here, on purpose. User agent, screen size, language, timezone and IP address are all readable without asking anyone's permission — which is exactly what makes them a fingerprint. The game reads none of them, so there is nothing to report. No IP lookup, no geolocation prompt, nothing inferred from either.

That is a decision rather than a limitation. If this ever does need breaking down by office, the way to do it without a fingerprint is to let each panel say where it is in its own URL — typed once per device, never sniffed.
