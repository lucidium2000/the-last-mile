What is recorded, and what is not

Every finished run sends three initials, the run's own numbers (score, blocks, rows, steps, subway rides, TAM wins, seconds, how it ended, which power-ups were collected) and a random id the browser made up for itself, so repeat plays can be counted without counting a person twice. The set of ids never leaves the server — this page only ever receives the count.

There are no device or browser statistics here, on purpose. User agent, screen size, language and timezone are all readable without asking anyone's permission — which is exactly what makes them a fingerprint. The game does not read them, so there is nothing to report. Same for location: no IP lookup, no geolocation prompt.

The By office figures above are not sniffed. A panel reports where it is only if its URL says so — open the game as …/the-last-mile/?site=penn1 on the Penn 1 panel and every score from it carries that label. Set it once per device. Anything unlabelled is counted as unlabelled, and nothing breaks.
